## 简介

PicoFilter 是一款面向 Windows 的图片管理工具，支持 JPEG、PNG、BMP、ICO 和 GIF 格式，可用于图片筛选、批量重命名、格式转换及数据分析。

## 主要功能

- **图片筛选**：按格式、分辨率等条件筛选图片。
- **批量重命名**：支持序号、文件名和日期等命名方式。
- **格式转换**：支持常见图片格式转换及相关参数设置。
- **图片搜索**：按文件名、格式、日期等条件查找图片。
- **图片导出**：支持复制、移动、隔离、删除及导出 Excel、压缩包。
- **数据分析**：统计文件数量、大小、格式分布等信息。
- **辅助工具**：文件夹概览、关键词标记、文件名拆分等。

## 运行环境

- 操作系统：Windows 7 或更高版本
- 运行库：.NET Framework 4.7.2
- 建议分辨率：1024 × 768 或更高
- 字体：安装 `Fonts/方正黑体GBK.ttf`
